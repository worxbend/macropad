# Display and LED pictures

Generated by the firmware simulator. Do not edit by hand: run `make ui-images` in `firmware/`
(needs ImageMagick for the GIF). Nothing here is a photo; no hardware exists yet.

| File | Shows |
| --- | --- |
| `demo.gif` | A scripted session, 20 frames per second: the pad from above to scale, the display at 3x, the input, and the USB reports the host would get. |
| `pad.png` | One frame of the demo. |
| `screens.png` | Every screen with its LED colours, captioned. |
| `led_timeline.png` | The 8 LEDs (rows, chain order) over the demo, with the screen shown and the film time. |
| `splash.png`, `media.png`, `edit_typing.png`, `nav.png`, `num.png` | Display only, 4x. |
| `layer_banner.png`, `knob_overlay.png`, `system.png`, `idle.png` | Display only, 4x. |
| `flash_hold.png`, `flash.png` | Display only, 4x: the two-knob hold and the bootloader hint. |

LED colours are brightened with a square-root curve so they read on a monitor.
Display pictures are decoded from the firmware's SPI bytes by the simulator's panel model.
The GIF holds 256 colours per frame, so the LED glow is slightly banded and a few pixels can be
off by a shade. The PNG files are exact.
The scenes are defined in `firmware/sim/src/scenes.rs`.
